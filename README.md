# Pilland

Moment Effects / Dynamic Island για Galaxy S24 Ultra: ένα ζωντανό νησάκι γύρω από την κάμερα με animations ελατηρίου, glow και πλήρη παραμετροποίηση.

**Λειτουργίες:** μουσική (εξώφυλλο, visualizer, seek, play/pause), κλήσεις, χρονόμετρα (του Ρολογιού και δικά του), λήψεις/πρόοδος, Android 16 Live Updates, φόρτιση, χαμηλή μπαταρία, φακός (με ένταση), ειδοποιήσεις με απάντηση, σίγαση/δόνηση, Μην ενοχλείτε, ακουστικά Bluetooth, ξεκλείδωμα, γρήγορο πάνελ (στιγμιότυπο, κλείδωμα, χρονόμετρα…).

**Εγκατάσταση:** κατέβασε το `Pilland.apk` από τα [Releases](../../releases/latest) → άνοιξε την εφαρμογή → δώσε τις άδειες.
